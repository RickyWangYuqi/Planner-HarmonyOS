# 序笺 · HarmonyOS 日程记录应用

序笺基于桌面 Planer 1.1.0 实际业务代码与设计令牌实现，是本项目的鸿蒙原生应用正式名称。保留当日 / 未来双列表、分组、进度、历史恢复和主题；使用 ArkTS、ArkUI、Stage 模型，编译与目标 SDK 为 26.0.0，最低兼容 HarmonyOS 6.1.1(24)。

当前鸿蒙应用版本为 **V1.2.0**，应用版本代码为 `1200000`。工程沿用现有脚手架，模块为 `entry`，包名为 `com.example.planerharmony`。数据仅保存在应用沙箱，不连接业务服务器。

应用名称统一为「序笺」：桌面 / 系统显示名、主页、设置、新手教程和组件预览均使用新名称。宣传语为「像便签一样轻巧，像清单一样有序。」；当前商店介绍见 [应用商店文案](docs/STORE-LISTING.md)。

项目目录 `PlanerHarmony`、包名、签名文件、资源标识、代码类名与 `planer_tutorial` 等存储键沿用既有技术名称，避免更名改变安装身份、影响历史数据或破坏文件引用；它们不作为对用户展示的应用名称。桌面来源项目 `Planer` 的名称和原文件路径保留原样。

本版本手机版介绍图见 [图片/手机版-20261027](图片/手机版-20261027/制作说明.md)：八张 1440×2560 高清竖版，包含周期打卡、自动接续、日历补卡及既有日程功能，附总览与可编辑源文件。

本版本平板介绍图见 [图片/平板版-20261027](图片/平板版-20261027/制作说明.md)：八张 MatePad Pro API 26 实拍横版，统一 2880×1920（3:2）、单张小于 5MB，附总览与可编辑源文件。

## 功能一览

### 日程

- 当日、未来日程的新增、编辑、永久删除；删除需确认。点击编辑按钮打开表单，点击日程正文不会误开编辑。卡片仅保留编辑按钮，永久删除位于编辑表单滚动内容末尾的「日程管理」区域，底部固定保留取消与保存；原日程操作面板已移除。
- 未来日程使用起始 / 截止日期区间。起始可不填，默认为当前所选日期的下一天；起始与截止通过两个选择项共用下方日历，默认选中必填的截止日期，可切换查看和清除起始日期。填写正文后点击「添加」，若未选择截止日期会自动切回截止日期选择项、显示提示并平滑滚动到时间安排区域；键盘打开时先收起键盘再定位，选择有效日期后提示消失。
- 当日未完成日程按真实日期跨日顺延，已完成日程在真实完成日结束后归档；未完成未来日程截止日到期后进入当日。启动、回到前台及前台定时检查日期。
- 「选择日期」可浏览真实今天及未来日期，未来起止日期打点提示，日期选择面板沿用日程编辑的圆角卡片分区。浏览未来仅预览顺延与到期分区，不提前归档今天已完成的日程；只有真实今天结束后才执行跨日归档，停在未来视图时也不会跳过真实午夜。回到今天时，所选未来日期新增的安排会回到未来分区。
- 勾选当日日程后显示删除线；勾选未来日程默认立即归档；可在设置开启完成后保留至截止日，保留期间再次勾选可取消完成。编辑进度支持未设置及 0–100%，设为 100% 完成，低于 100% 取消完成。
- 长按识别成功时立即开始浮起；浮起、跟手和松手落位共用一套连续动画，不再等待系统后续拾起阶段或切换另一张预览。手指移动时卡片直接跟随，松手后平滑回到实际落点；原地长按后松手也自然回落。卡片与分组共用阴影与弹簧效果，经过目标位置时展开与卡片高度相配的落位槽，相邻卡片弹簧避让。松手后提交排序、跨列表或跨分组移动；无效落点和取消不改变数据。卡片排序与移动通过长按拖动完成，当日移至未来时先回落再打开日期确认，取消不移动日程。拖至列表上下边缘会连续自动滚动，靠近边缘时逐渐加速；停住手指仍可滚动，离开边缘、松手或到达列表尽头即停止。
- 未来移到当日时保留隐藏起止日期；再次移至未来时自动填入仍有效的原区间，允许调整。
- 当日 / 未来之间的分割条可拖动，分区比例自动保存。API 26 的未来列表延伸到屏幕底部，日程可从悬浮底栏后方滚过；末尾留白让最后一条仍能滑到页签上方操作，拖动自动滚动的触发区域位于底栏上方。
- 两区列表下方仍有未完整露出的日程时，列表内容在底边逐渐透明；最后一条完整可见后恢复完整显示。渐隐保留日程卡片自身圆角，并连续经过未来区悬浮栏后方，不额外叠加有色阴影块。未来区按悬浮底栏上方的可操作范围判断，拖动日程时暂时隐藏提示；提示不拦截触摸。

未完成日程自动显示「延期 X 天」，依据原计划日与真实今天的日历天差计算，完成后隐藏。浏览未来时，尚未实际延期的旧计划显示「预计延期 X 天」；顶部同时显示未来预览说明与「回到今天」入口，区分顺延旧计划和在该日新建的安排。已知起止 / 截止日期继续保留；旧数据没有原计划日时，从迁移时可确认的日期开始记录，不推测更早的延期天数。

### 打卡

底部「打卡」页用于管理多个周期计划，采用系统圆圈勾选图标，新建按钮与日程页使用相同的加号图标，背景采用当前主题的淡染材质。编辑页按名称、分组（开启时）、开始日期、重复频率和「自动递增/接续」排列为圆角材质分区；日期与频率展开、收起都有动画。可选每天、每周指定星期或每月指定日期，每月不存在的日期自动跳过，不移到月底。今日清单按计划顺序同时显示待打卡与已完成项，完成或撤销后保持原位；已暂停及其它日期的计划另列，空状态可直接新增。

- 在设置开启「按分组显示日程」后，新建和编辑打卡可选择已有分组，再次点击已选项取消选择，也可创建新分组。新组先保留为表单草稿，随计划保存一起提交，同名分组直接复用；取消表单不保存草稿。新计划默认为未分组。编辑计划的分组会同步当前及未归档的关联日程，并用于后续周期；已经归档的历史保持原分组。关闭分组显示只隐藏选择区，不清除已选分组。
- 名称中的数字可自动识别，识别后提示可开启递增，默认保持关闭。例如「背单词289-298」识别为每期 10 个，下期名称为「背单词299-308」；「看网课第10节」默认每期增加 1，下期为「看网课第11节」。可调整每期数量或单个编号的步长，不再单独填写或展示范围，也无需填写目标说明和备注。
- 名称识别后可直接点「点击开启自动递增/接续」，开关同步开启，并提示下一期的完整名称；直接打开开关也有相同反馈。编号提示可按周期自动递增，区间提示可按周期自动接续；一次只识别一种，遇到多组数字会说明开启条件。开启即确认接续规则，以后按周期自动生成，不再逐期确认。关闭后按固定名称打卡，也可随时手动改名；既有周期名称保持原样。数字无效或超出安全范围时提示调整，不静默重复旧内容。
- 按真实今天生成打卡日程；不会提前进入未来日程，主页浏览未来日期也不触发生成或把未来打卡放入当日列表。已生成但未完成的打卡沿用日程延期规则；完成后当天保留完成状态，真实跨日后进入历史日程。主页、打卡页及桌面卡片的完成状态同步，同一条目同一日期仅保留一个周期。
- 今日打卡直接在原位完成或撤销，不弹出完成确认页。「完成打卡」使用淡主题色且不带勾选图标；完成后切换为中性色的「撤销」与恢复图标。按钮只有内部图标和文字切换，卡片位置与大小不变，详情中的今日记录也采用相同操作。
- 「补卡」进入独立二级页，日历始终展开，每天标出完成、已补卡、已提前打卡、未完成或「当日无打卡项」。选择过去未完成的有效日期后补记，成功后留页继续选择。已生成周期显示它自己的历史名称；从未生成内容的过去日期保留空输入，由用户填写当天实际完成的内容，不预填当前计划名称。补卡不推进当前内容，重复及无打卡项的日期不能提交。
- 补卡日历和详情时间线可预览未来周期：名称中的编号或区间按所选日期及有效打卡周期推算，休息日和暂停日不占一个周期。预览不保存日程，也不改变当前进度。有效未来日期可直接「提前打卡」，保存独立的当期名称快照和实际完成时间；到达真实周期日后才进入日程。时间线内提前完成后，状态仍标为「已提前打卡」，原按钮切换为「撤销」；撤销保留当期名称，回到未完成后可再次提前打卡，不推动当前进度，也不产生未来日程。补卡日历中的已提前完成状态仍只读，在时间线撤销后可回日历重新提前打卡。不提供独立未来页面或未来编辑入口。无法生成有效内容时先调整计划。
- 详情时间线按日期从早到晚排列，打开时定位今天，上翻查看历史，下翻查看未来。点击过去的有效周期进入独立「历史计划」页，只提供该期的撤销或补卡；保留当时名称、实际完成时间及补卡标识，未生成过的周期明确显示未记录当期内容。
- 「今天 / 全部计划」通过滑块切换，标题下方的分节与卡片横向过渡，整体统计保持原位；进出内容跨过完整屏幕宽度并在内容区裁切，避免边缘残留旧卡片。卡片右上角使用与日程相同的居中编辑图标进入详情。详情中的统计、两行两列的计划管理和各条记录采用一致的圆角材质卡片，周期总数放在统计卡片右上角。新建仅使用原生半模态入场；从详情编辑、补卡或查看历史时保留二级页面转场，返回按钮及系统返回先回详情，关闭按钮关闭整张面板。
- 页面向上滚动时，内容穿过固定的「打卡」标题、新建按钮和状态栏后方，渐变模糊效果与设置页一致。补卡页滚动内容在底部逐渐透明，不叠加实色遮挡；固定提示和操作按钮保持清晰。详细用法集中在新手教程，首页和编辑器只保留必要提示。
- 支持暂停、恢复和永久删除。暂停与恢复直接生效，无需确认；暂停后显示暂停符号与「已暂停」，再次点击恢复；文字和符号都随当前状态同步更新。暂停保留既有日程，停止生成新周期。删除仍需确认，确认后该计划、全部打卡记录与关联日程（含历史日程）一并永久移除，不保留已删除条目列表。已移除「跳过」功能，旧跳过周期恢复为未完成。普通历史日程列表的删除 / 清空仍不影响尚存计划的独立打卡记录；这些历史打卡可恢复为原周期的未完成状态，不能恢复为未来日程。
- 单条及整体概况展示累计次数、完成率和连续打卡，均截至真实今天统计；未来提前完成的周期到期后才计入。遗漏及旧跳过周期按未完成计算；休息日、暂停日不打断连续值，今天尚未完成时保留此前连续值。整体连续值要求当日所有应打条目均完成。更改频率后，过去日期仍按当时的频率统计。
- 数据与日程一同保存在本机，退出后仍可继续查看。保存失败显示重试入口。

未来撤销及打卡分组的检查范围见 [打卡分组与提前撤销](docs/CHECKIN-GROUP-UNDO-QA.md)。此前未来周期预览、提前打卡和历史入口的检查范围见 [打卡未来周期与历史记录](docs/CHECKIN-FUTURE-QA.md)。

### 分组

- 设置中开启分组显示后，新建 / 编辑表单可选择分组或创建分组。再次点击已选分组可取消选择。
- 同名分组直接复用；尚未提交的新分组为表单草稿。填写组名后，可以先点「创建并选中」，也可以直接点日程的「添加 / 保存」，组名会与日程一并提交。空白名称不改变已有选择；取消创建或取消整张表单不保存新分组。
- 已保存的空分组继续保留，可在之后的日程中复用。历史中的分组不会在读取时复活已删除标签。
- 已有分组使用圆角材质标签，选中时通过主题淡染与文字强调区分，不再叠加外层蓝框；新建入口以加号区分，普通材质回退下保留虚线轮廓。长按分组标签进入删除状态，标签轻微摇摆，删除叉号位于右上角；点击标签退出删除态。删除已保存标签立即作用于当日与未来两区，即使取消表单也不撤回。组内日程保留并移到未分组末尾。
- 分组标题上的删除按钮只处理该分区；另一分区仍使用同名分组时保留目录。未分组不能删除。分组标题可整组拖动调整顺序；长按识别时，可见组员从各自位置缩拢为叠层圆角卡片，显示组名、数量及前两条摘要；松手后连续展开到实际落位位置，取消时展开回原组。收拢、跟手与展开沿用同一套弹簧动画。
- 关闭分组仅隐藏分组信息，保留任务所属分组与自由排序；重新开启会把同组任务聚拢，保持组内相对顺序。

### 历史日程

从「设置 → 历史日程」进入，按归档日期倒序展示。

- 原计划日等于当前所选日：恢复到当日。
- 原计划日在当前所选日之后：直接恢复到未来，保留原截止日期。
- 原计划日已过或缺失：选择恢复到当日或新的未来日期。
- 支持单条永久删除和清空全部历史，均需确认。恢复日期面板与日程编辑采用相同的圆角材质卡片分区，保留原有恢复规则。

### 日程显示设置

| 设置 | 默认值 |
| --- | --- |
| 自动编号（两区各自从 1 开始） | 开 |
| 未设进度默认显示 0% | 关 |
| 完成后自动定位下一项 | 关 |
| 按分组显示日程 | 关 |
| 未来日程完成后保留至截止日 | 关 |
| 当日区域占比 | 45%，小屏按最小可用高度约束 |

自动定位仅在勾选完成当前第一个未完成的当日日程时推进；编辑、取消完成或普通增删不误触发定位。定位锚点随数据保存，关闭开关清空锚点。定位方式是把下一项顶到列表可视区顶部；列表已滚到底部（下方没有内容）时不再滚动，避免为末尾几项做多余位移。

开启「未来日程完成后保留至截止日」后，已完成项留在未来列表原位，显示勾选和删除线；截止日当天仍保留，次日直接归档到截止日的历史，不转入当日。未完成的到期未来日程仍按原规则转入当日；保留项在截止日当天取消完成，也立即转入当日。关闭开关会立即将当前保留的完成项归档，之后点击完成即消失。应用和桌面大卡共用此设置，跨日、多日未打开也按同一规则处理。

### 外观与页面

| 设置 | 默认值 / 可选值 |

| 主题模式 | 跟随系统；可选浅色、深色 |
| 配色预设 | 海盐；可选森林、日落、墨影 |

主页、打卡与设置是底部页签中的三个同级页面；API 26 使用原生悬浮样式，6.1.1(24) 使用普通底栏。历史日程从设置进入，返回后仍停留在设置。设置与历史标题固定在状态栏下方，内容滚动时经过标题和透明状态栏背后的渐进模糊区，再滑出屏幕；设置首节与大标题间距收紧，保持与页面分节节奏一致；设置不显示返回按钮，历史保留返回入口。手机与窄窗口保留当日 / 未来上下分区，首个分组行与未开启分组时的首张日程卡片共用列表顶部留白，标题行容纳完整的圆角删除按钮，并收紧行后间距；两区保持相同的标题间距；自动保存失败时显示重试提示。

编辑、新建当日与未来日程沿用统一半模态高度，正文按「日程内容、时间安排（未来）、分组（开启时）、完成进度（编辑时）」分区排列，支持沉浸材质时，内容、时间、分组、进度和日程管理分区使用常规厚度的原生沉浸光感，随内容展开与收起平滑调整高度；不支持时保留清晰底色、细亮边和柔和阴影。统一标题和间距，必填与可选标记靠右显示，日程输入框以更实的主题底色和细边线独立呈现，聚焦时使用主题色强调。未来时间安排只显示一份日历，避免连续两个大日历占用滚动空间。取消与添加 / 保存固定在底部，编辑中的删除独立放在正文末尾的「日程管理」，保留确认流程。分组提示使用简短辅助文字，不再单独套入一个大底板。

配色来自桌面八套明暗主题；布局使用 vp、文字使用 fp、采用系统字体，触控按钮约 44 vp。卡片、按钮及表单统一为矩形圆角；官方线形 / 实心 SVG 与系统符号覆盖全部图标，无须额外下载。主题模式支持点击或横向拖动选择，选中滑块跟随手势轻微伸缩并以弹簧回弹落位，文字位置固定。主题颜色以 360 毫秒非线性缓动切换，按压、展开与切页采用弹簧曲线，滚动列表在边界提供回弹。

API 26 原生底部 Tabs、半模态表单、确认弹窗和受支持系统组件使用平台沉浸材质，厚薄与算力效果由系统适配；低算力档使用系统默认的有色背板、边框和阴影，不再被应用的透明赋色覆盖，不额外叠加毛玻璃。编辑、日期等半模态及教程采用浅色中性白、深色中性灰的背板，不叠加配色预设的主题染色；高算力档适度加厚，中算力档保持与悬浮底栏一致的通透材质，低算力档使用系统默认背板；普通确认弹窗保持原厚度；旧系统通过版本保护回退到普通底栏与可读弹层。分组标签、新建分组、进度快捷按钮（0 / 25 / 50 / 75 / 100%）、取消、添加 / 保存、删除及对应加号 / 关闭 / 删除图标按钮使用统一超薄原生沉浸光感材质，中高算力档的普通按钮透出后方页面，强调态保留轻主题色；分组只保留一套系统高光轮廓，不支持时回退为轻色按钮，轮廓直接画在真实按钮上。日程输入框保持更实的主题内凹底色，日历输入区保留轻色，不额外叠加模糊采样；普通任务卡与设置卡保留轻毛玻璃效果。沉浸材质受设备能力与组件位置限制，不代表每个按钮都具有系统沉浸光感。手机表单使用原生底部半模态，平板中宽窗口使用居中面板；键盘弹出时只调整表单可用高度以保持操作按钮可见，透过材质看到的底层主页保持原位置与尺寸。页面采用全屏内容布局与透明系统栏，首页控件和滚动内容初始位置按实际顶部安全区避让，固定标题由系统导航组件避让；根背景延展至顶部状态栏与底部手势区，宽屏限制内容宽度。

早期已在真机复验固定标题与滚动模糊、主题滑块、图标配色、分组直接保存、单卡排序 / 跨区移动和编辑删除；现场自然跨午夜也完成了未完成日程顺延。范围与最终截图见 [本轮交互验收记录](docs/INTERACTION-QA.md)。包含最后一次落点状态修订的检查、签名构建、安装和启动均通过；已执行范围与未覆盖场景分开记录。

### 平板与多窗口适配

工程支持手机与平板，跟随系统自动旋转设置。布局依据当前窗口宽度变化，横竖屏、分屏和悬浮窗共用同一套规则，文字与按钮保持原尺寸。

- 窗口达到 840vp 时，主页将当日与未来日程放在左右两栏，每栏独立滚动；可长按排序或跨栏移动，分组整组排序规则不变。两栏在底部导航上方留出操作空间。
- 更窄的窗口恢复上下分区，可拖动中间分隔条调整比例；宽屏排布不改写已保存的上下比例。
- 设置页在宽屏分成两栏：左侧日程显示与历史，右侧主题与帮助；窄窗口依次排列。历史列表保持适合阅读的最大宽度，固定标题与滚动渐进模糊继续保留。
- 中宽窗口的编辑面板居中并限制宽度，简单的新建当日表单使用较窄面板；足够宽时，内容、分组与时间安排分栏，编辑进度与删除继续在表单内。底部取消、保存按钮保持易触及宽度；日历仅省略全空周，日期触控尺寸不缩小。手机表单保持原排版。
- 首页最大宽度为 1280vp、设置 1184vp、历史 960vp，避免超宽窗口将单行内容拉得过长。本版本平板介绍图单独存放在 [图片/平板版-20261027](图片/平板版-20261027/制作说明.md)，旧版保留在 `图片/平板版`，不替换手机版图片。

### 新手教程

首次打开应用时，从底部弹出接近全屏的原生半模态说明面板，保留简要标题、图标条目和底部按钮排版。八项说明包括当日 / 未来日程、编辑与完成、打卡管理、名称数字自动接续、长按拖动、分组、桌面组件，以及历史与外观设置。八项说明各用不同图标：打卡使用系统勾选符号，分组使用文件夹符号，与桌面组件的网格符号区分。本轮更新后已看过旧版教程的用户会再看到一次新版说明。面板正文首帧挂载后即启动条目，与半模态上升并行，从上到下按 55 毫秒间隔依次向上弹出，以非线性弹簧自然落位。点「开始使用」、点「稍后」、下滑面板或使用返回手势均可关闭，之后启动不再自动打扰；随时可从「设置 → 新手教程」重新查看。底部仅保留回看提示，不显示「本机自动保存」。说明不要求操作日程，也不改变数据、主题或当前页面。

内容集中在 `entry/src/main/ets/tutorial/TutorialConfig.ets`，调整说明只需更新条目标题、文案与图标，入场顺序和间隔自动按配置派生；组件保留圆角、当前主题和自然入场动画。常规手机竖屏集中显示一页，小屏或大字体时正文可滚动，「开始使用」始终可见。首次使用标记单独存入 Preferences，保存失败可重试。

### 桌面卡片

长按桌面应用图标，系统列表中「卡片」由系统托管，点击后展示本应用的「日程卡片」；也可在桌面长按卡片拖拽改尺寸，卡片按实际几何重新取档。

| 规格 | 信息量 |
| --- | --- |
| 小卡 2\*2 | 日期、完成比、一条摘要、当日日程列表（可滚动）与进度条 |
| 中卡 2\*4 | 左侧日期 / 环形完成比（环内显示数字）/ 未来数量，右侧当日日程列表（含分组与进度） |
| 大卡 4\*4 | 日期、完成比、进度条、当日日程列表，列表末尾接「未来日程」分区（含起止日期） |

- 列表可滚动，条目数不按尺寸截断，超出可视区的部分滑动查看（原「另有 N 项」提示随之取消）。条目顺序与列表一致：勾选完成后留在原位并显示删除线，不再把已完成项排到末尾；当日全部完成时显示完成文案。
- **卡片内可直接勾选完成**：点按条目即通过 `postCardAction` 的 message 事件交给卡片扩展，扩展按与应用相同的 reducer 写回 `data.json`（独立 `.card.tmp` 原子替换 + 备份），再把结果推回所有卡片实例；点按卡片空白区域打开应用。主应用回到前台时会比对文件并采纳这次外部写入，避免两边互相覆盖。
- 大卡的未来日程同样可直接完成，遵循「未来日程完成后保留至截止日」：默认立即归档并移除；开启后保留原位、显示完成标记和删除线，可再次点击取消，截止日结束后归档。
- 完成与取消都有过渡动效：勾号缩放淡入淡出、删除线渐显渐隐、文字颜色渐变；未来日程在立即归档模式下完成后淡出移除，保留模式下原位切换完成状态。
- 主题：配色跟随应用的主题模式与配色预设。「跟随系统」时改用 `resources/base` 与 `resources/dark` 下的同名色，系统切换深浅色由卡片渲染进程直接换色，不依赖提供方进程存活；应用内切换主题后推送，退到后台时再补推一次。当前真机从卡片进入应用后返回时，来源卡片在系统返回动效中仍可能短暂显示旧色，随后与其它实例一致；此现象尚未完全消除，见 [自动定位与卡片返回验收](docs/SCROLL-FORM-QA.md)。
- 背板采用随主题变化的斜向渐变：海盐淡蓝、森林浅绿、日落暖杏、墨影浅紫；深色使用对应的沉稳色调。左上阅读区保持干净，右下主题色更鲜明，三种尺寸风格一致；浅色辅助文字相应加深以保持清晰。渐变不受桌面壁纸明暗影响，系统圆角和现有内容布局保持一致；主题模式及配色继续跟随应用。视觉与验收范围见 [主题渐变验收](docs/WIDGET-GRADIENT-QA.md)。
- 卡片始终展示真实今天，不沿用应用保存的未来预览日期；三种规格均能显示实际延期提示。卡片写回操作按真实今天执行，回到应用时采纳同一份状态。
- 数据同步：主应用每次保存成功、回到前台后主动推送；卡片侧按 `updateDuration` 定时刷新，并在应用未打开时按同一套日期规则在内存中顺延到真实今天（不写回数据）。
- 卡片添加 / 移除由 `onAddForm` / `onRemoveForm` 记录到共享首选项（使用应用级 `context` 才能跨进程共享）；每次推送前用 `getPublishedRunningFormInfos` 与注册表对账，补齐缺失实例、剔除已被移除的卡片。

### 窗口行为与功能边界

手机端不暴露 Windows 专属开关；保留数据字段以维持版本兼容，并在应用生命周期中处理前后台切换。

| 桌面能力 | 桌面默认值 | 手机端处理 |
| --- | --- | --- |
| 窗口置顶 | 关 | 不申请悬浮窗，不提供桌面置顶 |
| 任意应用全屏时隐藏 | 关 | 使用系统前后台调度 |
| 失焦缩小、鼠标悬浮展开 | 关 | 使用系统后台与任务切换 |
| 关闭时退出 / 托盘 | 退出程序 | 返回手势、系统任务管理，无托盘 |
| 开机启动 | 关 | 不申请后台启动能力 |
| 自由调整桌面窗口尺寸 | 最小 380×520 | 手机自适应及双列表比例调整 |

打卡提供按周期生成当日日程；普通日程仍不提供重复规则。当前不提供搜索 / 筛选、通知提醒、导入导出、账号同步或业务网络接口。无须申请通知、网络或公共文件访问权限。

## 功能变更记录（V1 → V1.1.0）

以下只记录功能层面的新增、调整与移除，不包含缺陷修复与排查过程。桌面卡片是 V1 之后新增的整块功能，其中「调整」指相对早期实现形态的变化。

### 新增

- **桌面日程卡片**：三种规格（2\*2 / 2\*4 / 4\*4），可在桌面拖拽改尺寸并按实际几何重新取档；点按卡片打开应用。
- **卡片内勾选完成当日日程**：点按条目即完成 / 取消，写入与应用同一份数据，并同步桌面上所有卡片实例。
- **卡片日程列表可滚动**：条目数不再按尺寸截断，超出可视区的部分滑动查看。
- **大卡未来日程**：当日列表末尾新增「未来日程」分区，显示日程与起止日期，可直接勾选完成，保留与归档规则跟随设置。
- **卡片主题跟随**：卡片配色随应用的主题模式与配色预设变化，包含「跟随系统」时深浅色的自动切换。
- **完成态过渡动效**：勾号缩放淡入淡出、删除线渐显渐隐、文字颜色渐变，取消完成反向播放；未来日程完成后淡出再移除。
- **日程延期提示**：实际延期显示天数；未来预览使用「预计延期」，并提供常驻的未来预览说明与回到今天入口。
- **未来完成保留设置**：可选保留至真实截止日结束，默认关闭，应用与大卡规则一致。
- **卡片与应用双向同步**：主应用在保存、回到前台、退到后台时推送；卡片内写入的改动在应用回到前台时被采纳。

### 调整

- 卡片条目顺序与列表保持一致：勾选完成后保持原位置，不再把已完成项排到末尾。
- 中卡进度由横向进度条改为圆环，环内显示「已完成 / 总数」；左列日期与右侧标题顶对齐、未来数量与列表底部对齐。
- 完成态配色统一跟随主题强调色：应用内勾选框、顶部「已完成 X / N」进度条、卡片勾号与圆环均不再固定使用绿色。
- 移除大卡底部的「未来 N 项 / 本地保存」汇总行。
- 新建、编辑与移动表单统一为同一高度：当日分区的新建表单不再比编辑表单矮一截。
- 日期浏览与真实跨日分离，浏览未来不会提前归档当天完成项；未来日期新建的计划返回今天后进入未来分区。
- 分组、取消、添加 / 保存和删除按钮接入组件级沉浸光感材质；教程条目从正文首帧起与面板上升并行入场。
- 自动定位（完成后定位下一项）：改为把下一项顶到可视区顶部；列表滚到底部后不再滚动。

基本复现流程：

1. 首次打开，新增两条当日日程和一条有起止日期的未来日程；编辑其中一条进度为 50%，查看编辑与日历的轻色叠层。
2. 进入设置并滚动，确认标题保持固定且背板渐变模糊；进入历史页检查固定标题与返回。点击、慢拖及快速拖动浅色 / 深色 / 跟随系统滑块，确认选中与实际主题一致。
3. 开启分组。新增或编辑时填写组名，直接点主「添加 / 保存」，确认任务归组且重启后保留；再检查同名复用、空白名称、取消创建与取消整表。
4. 长按卡片观察识别时立即浮起，先原地松手确认回落，再依次拖过前、中、末尾落点，检查空槽和相邻卡片避让；松手检查同一卡片连续落位及实际顺序。分别测试跨组、未来移至当日、当日移至未来后的日期确认，以及无效落点和取消。
5. 确认卡片仅保留编辑按钮，原操作面板入口已移除。进入编辑表单底部点击「删除日程」，验证取消确认保留草稿、确认删除后关闭表单。
6. 勾选当日日程并切换到下一天，检查归档与顺延；关闭新开关时勾选未来日程检查立即归档，开启时检查保留、取消完成、截止日当天保留与次日归档，在历史页恢复、删除或清空；桌面大卡执行相同完成 / 取消流程。
7. 切换四套配色，调整分区比例后重启，确认数据与设置保留。6.1.1(24) 应使用普通底栏，API 26 使用悬浮底栏；最低版本安装与系统真实深浅切换需单独验收。
8. 长按分组标题，检查可见日程向摘要卡收拢；原地松手、取消或换位后检查展开到真实位置。缩小当日分区，拖动分组到上下边缘，检查连续滚动与实际排序；长按表单分组查看右上角叉号及摇摆。分别聚焦日程内容、新建分组输入框，检查键盘上方按钮可见且背景主页不动。未来表单输入正文但不选截止日期，点击「添加」检查提示和定位；滑动未来列表检查底部延展及最后一条的可操作性。超长列表、窄屏与大字体仍需扩展验证。
