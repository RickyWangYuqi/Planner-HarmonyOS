## 日期与兼容数据

- AppData.currentDate 为浏览日期；新增 lastRolloverDate 为真实跨日进度，日期选择不会推动它。
- Task.scheduledDate 为可确认的原计划日；Task.completedDate 为完成操作对应的真实日。自动顺延保留计划日，明确重新安排 / 历史恢复会更新它，原有隐藏起止日期继续保留。
- 新字段默认空 / null；旧数据通过 normalizeData 迁移。没有原计划日的旧当日任务从可确认的迁移日期开始，不从 createdAt 倒推猜测延期。已有明确截止日且已过时可用于计算。
- 未来日期新建“当日”任务保存所选日期，返回今天后进入未来；预览中提前完成这类未来计划时，仍执行未来完成的保留 / 立即归档设置。
- 保留模式的截止日判断不随浏览日提前。实际截止日当天保留，结束后归档；完成当日日程的历史分组用真实完成日，原计划日另存。
- 卡片只读快照始终调整到真实今天，避免将应用未来预览当作桌面的今天；只读刷新不写文件，卡片真实勾选写回按真实今天处理。
- 日期天差用 Date.UTC 的日历天计算，避免夏令时日长差导致延期天数偏一；回归包含闰日。

原数据 JSON 版本仍为 1，保留 .bak 原子写入机制。不会自动把以前已归档的历史批量搬回列表，以免猜测用户原本的归档意图；历史仍可按原流程恢复。

- 11706006：ImmersiveMaterial、ImmersiveStyle、THIN 不支持 form application。

试验代码通过 finally 恢复，随后最终常规构建成功。日志保存在忽略目录 `.tooling/v110-final/widget-material-build.log`，避免将失败试验混入交付版本。后续只有在工具链明确支持完整构造与兼容保护后才适合重试，当前不移除最低版本支持、不导入未公开接口。
