## 行为

### 新手教程

首次打开时使用原生底部 `bindSheet`，高度 94%，支持拖动关闭与返回，保留标题、图标条目、底部按钮和回看提示。面板出现后，条目按配置顺序每隔 70ms 向上位移、淡入并轻微回弹；使用现有非线性弹簧，不叠加自绘全屏教程遮罩。六项说明包含新的桌面组件条目，使用官方系统卡片网格符号；教程底部移除“本机自动保存”。

按钮关闭与原生面板消失共用幂等确认逻辑，首次使用标记仍独立存储。配置版本不变，已确认的现有用户不会因为更新再次自动弹出；仍可从「设置 → 新手教程」回看。正文在小屏、大字体时滚动，底部操作保留。

### 未来日程保留

新开关位于「设置 → 日程显示设置 → 未来日程完成后保留至截止日」，默认关。持久字段 `Settings.retainCompletedFutureUntilDue`，旧文件缺失字段按 false 读取，数据版本和安装标识均保持。

- 关闭：点击未来日程完成后立即从列表移除，归入点击当天的历史，维持原行为。
- 开启：点击完成后保留原位，显示勾选和删除线；再次点击取消完成。截止日当天仍保留，跨到次日时直接归入截止日的历史，保留真实完成时间；多日未打开时也按原截止日归档，不重复归档、不经过当日列表。
- 未完成未来日程到期仍进入当日；保留项在截止日当天取消完成，同样立即转入当日。
- 关闭已开启的开关时，当前保留的完成项立即归入当天历史；历史仍可按原规则恢复。
- 编辑百分比的既有语义保持；保留模式下，截止日当天编辑已完成项仍留在未来列表。

应用与桌面扩展均使用 `PlanerEngine`；卡片写回从同一数据文件读取新设置。大卡数据新增 `futureMarks` 与保留开关，完成保留时原位显示并允许取消，立即归档时沿用移除效果。纯刷新跨日快照仍只在内存计算，后续应用回前台或卡片真实操作时落盘。
