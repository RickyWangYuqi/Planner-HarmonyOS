# 平板适配与验收

日期：2026-10-22 至 2026-10-23。最终代码构建后已覆盖安装到 HUAWEI MatePad Pro，物理屏幕 2800 × 1840px。

## 配置与实现

- 主模块和测试模块原本已包含 `phone`、`tablet`，本轮保留；主 Ability 增加官方 `orientation: "auto_rotation"`，遵循系统旋转锁定。
- 编译与目标 SDK 保持 `26.0.0`，最低兼容配置保持 `6.1.1(24)`，签名与安装身份不变。
- 使用 `ResponsiveLayout.ets` 按窗口 vp 宽度分档，不依据设备名称判断；840vp 起双栏，600vp 起采用受限宽度面板。
- 宽屏双栏具有相同可用高度，在导航栏上方留白。拖动命中仍按真实节点的横纵坐标计算，不将纵坐标相同的另一栏误判为当前栏；宽屏不再重复扣除手机未来区的底栏遮挡高度。
- 窗口跨越断点时清理正在进行的拖动，重排列表不改写上下分区比例。设置和历史内容有最大阅读宽度，编辑器按实际面板宽度分栏。

官方依据通过项目 DevEco CLI 文档读取：`faqs-arkui-374`（自动旋转），`ts-universal-attributes-sheet-transition`（SheetOptions.width、preferType 及居中高度范围）。没有修改 SDK 版本字符串或签名。

## 验证边界

当前平板系统版本字符串为 `6.1.0.135`，设备报告 `apiVersion: 24`；已验证该设备的兼容样式，不据此声明 API 26 平板原生材质效果。自动旋转字段已通过构建，未实际转动物理平板验证竖屏、旋转中的手势与键盘组合；相关窄宽断点已用同机悬浮窗与纯函数测试覆盖。未量测动画帧率、大字体或外接键鼠，也未在本轮重连手机实测；手机既有布局分支及回归保留。
