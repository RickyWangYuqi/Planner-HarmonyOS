# 启动右滑修复验收（2026-10-20）

## 原因与证据

主页、设置 Tab 外叠加的历史日程页此前总在数据就绪时创建，即使从未进入过历史页，也会设置整页 `translate(x: 100%)`。首次建树与主题动画处于相邻布局更新时，历史页从默认位置向右侧隐藏位置移动。

真机连续冷启动截图 [109-1](screenshots/109-start-before-1.jpeg) 捕获到历史标题和历史列表覆盖主页右半边；[109-2](screenshots/109-start-before-2.jpeg) 则已退至右侧。临时逐帧日志也确认启动时历史标题节点已存在。日志坐标返回属性目标位置，不能用它推断 RenderService 的逐帧插值；右滑的直接证据以截图为准。

## 修复

仅修改 `entry/src/main/ets/pages/Index.ets`：

- 历史页初始不创建，首次显式导航到历史时才创建。
- 首次进入使用官方 `TransitionEffect.translate` 插入转场；后续进出继续沿用原有弹簧位移动画。
- 已访问的历史页保留实例和滚动状态，不因返回设置而销毁。
- 临时 `probeStartup` 诊断代码已移除。

本次为缺陷修复，不调整功能入口、教程、业务数据、主题设置或构建配置，因此未修改 README 的功能描述。

设备没有 `screenrecord` 命令，因此采用系统 `snapshot_display` 连续 JPEG 截图；这不提供动画帧率或所有设备的性能结论。
