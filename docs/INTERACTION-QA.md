## 本轮中间失败与修复

- 首次启动崩溃：历史标题 `stackBuilder` 需显式保留组件 `this`，已改为绑定组件上下文的回调，修复后部署通过冒烟。
- HDS 显式 `LengthMetrics.vp(0 / 20)` 模糊偏移在本机 SDK 检查通过，但真机运行时解析不接受；已省略可选偏移，使用平台默认 0 → 8 vp。
- 固定标题偏移 / 重叠：非全屏窗口本身已避让状态栏，HDS 再次应用 safeTop 会形成双重偏移。该轮设置 `titleBar.avoidLayoutSafeArea=false`、`enableComponentSafeArea=false`，并在标题配置后指定 MINI 模式；36 / 37、39 / 40 为最终复验依据。
- SVG 变白：旧矩阵把颜色通道与平移单位混用，先前代数测试也采用了错误单位假设。现使用官方等价的 Drawing SRC_ATOP 工厂，向 `common2D.Color` 传入 0–255 通道；35 / 38 证明真机明暗配色已恢复。临时 8 项接口 / 混色契约测试涵盖 93 种真实主题颜色，但仍不代替这两次渲染复验。
- 同一插入索引切换目标分组时预览归属需刷新：`Index.dropGroup` 改为 `@State`；最终 17 文件检查、37 项拖动回归、签名构建及启动均通过；复杂分组边界的全部真实手势未穷举。

26–34 为过程中保留的截图，包括命名中带有 fixed / final 的 [26](screenshots/26-settings-fixed-title.png)、[27](screenshots/27-settings-scrolled.png)、[29](screenshots/29-history-back-material.png)、[30](screenshots/30-settings-title-final.png)。这些文件名不代表当前最终验收；28、31–34 仅用于上表限定的局部行为，标题和图标结论以 35–40 的对应截图为准。[25](screenshots/25-group-before.png)是分组修改前的状态。
