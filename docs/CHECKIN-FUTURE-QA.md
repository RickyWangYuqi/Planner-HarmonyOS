## 本轮实现

| 用户关注项 | 当前行为 |
| --- | --- |
| 未来日期内容 | 补卡日历和详情时间线显示所选日期按有效周期推算的完整名称。编号递增、区间接续都按每天 / 指定星期 / 指定月日计算，休息日和暂停日不占周期；不存在的月日跳过。 |
| 提前打卡 | 有效未来周期可直接提前完成，使用当天的推荐内容，保存独立名称快照与实际完成时间。未来只提供此操作，不增加未来编辑页，也不提供未来撤销。已完成显示“已提前打卡”。 |
| 未来与日程隔离 | 查看未来不创建日程；提前完成也不写入未来日程或当前日程，到真实周期才进入日程。主页浏览未来不会提前生成打卡，当前计划名称和进度不被未来操作推动。 |
| 统计隔离 | 次数、完成率及连续值截至真实今天计算，未来提前完成的周期尚不计入。到达对应真实周期后，按该周期的完成状态计入。 |
| 时间线顺序 | 记录按日期升序排列，默认定位今天；上翻历史，下翻未来。未来预览和过去记录分别保留，显示排序不破坏补卡查找最近遗漏周期的顺序。 |
| 独立历史打卡页 | 只有过去有效周期可进入。读取原名称和实际完成时间，只提供撤销或补卡；没有快照时显示未记录当期内容，补卡要求填写实际名称，不以今天的数字代替历史。 |
| 移除跳过 | 页面不再显示跳过入口，领域层拒绝旧跳过动作，旧版跳过周期迁移为未完成。今日项不会因完成或撤销而重新排序。 |
| 暂停与删除 | 暂停、恢复直接执行，不显示确认弹窗；暂停时使用暂停符号与“已暂停”，再次操作恢复。文字和符号都读取当前实时状态，修复同一页面复用时闭包捕获旧符号的问题。删除仍需确认，并永久移除计划及全部关联记录和日程。 |
| 操作按钮与图标 | 新建加号与日程页一致。“完成打卡”使用淡主题色且不带勾选；“撤销”使用中性色与恢复图标。未来完成按钮只读，转场仍限定在固定按钮内部。 |
| 教程图标 | 八项说明使用不同图标；分组使用文件夹，桌面组件继续使用网格，打卡使用勾选符号。 |
| 列表切换 | “今天 / 全部计划”切换时，内容跨过完整屏幕宽度并在内容区裁切，避免留白处残留退出中的卡片。 |
| 补卡提示与材质 | 既有历史名称、无快照空输入和无打卡项状态继续保留。底部仅对滚动内容作透明度渐隐，提示和按钮不受遮挡，不新增主题色蒙版。 |

## 边界与后续确认

- 未来投影是只读推算，已有周期快照始终优先。编辑当前计划不会重写已完成或已提前完成的周期名称；编号溢出或规则无效时禁用提前完成并提示调整。
- 没有历史快照的过去日期不能可靠还原当时名称，继续要求填写实际内容；不以未来推算方法倒推或补造历史快照。
- 日期判断和统计使用真实今天，区别于主页浏览日期。提前打卡保存实际操作时间，周期日期仍为选定未来日期；到期接入、统计计入和跨多日处理已做自动化回归，本轮自然跨午夜的手机过程尚未记录。
- 未来记录不开放撤销或编辑入口，领域校验也拒绝将普通撤销、补卡或手改名称动作套用到未来周期。
- 本轮尚未完成平板 / 多窗口、API 24、不同系统性能档位、大字体、长时间连续操作和逐帧性能量测；不以本机单一 API 26 手机结果推断这些场景已通过。
