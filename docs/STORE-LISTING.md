# 序笺 · 应用商店文案

## 应用名称

序笺

## 宣传语

像便签一样轻巧，像清单一样有序。

## 简短介绍

把今天与未来分开放好，用轻巧的方式安排每一天。

## 应用介绍

序笺是一款简洁、清爽的日程记录应用。把随手记下的事情，整理成清楚的日程。

- 日程分区： 当日事项与未来计划分开管理。
- 进度记录： 支持完成勾选与百分比进度。
- 拖动整理： 长按排序，支持跨分区、跨分组移动。
- 分组管理： 按自己的方式归类日程。
- 历史回顾： 查看已归档事项，按需恢复。
- 个性外观： 浅色、深色、跟随系统及多套配色。同时适配鸿蒙系统最新的沉浸光感材质

无需注册，本机自动保存，打开就能开始记录。
