## 制作方式

2026-10-20 在 HUAWEI Mate 80 Pro Max 实际运行应用，使用虚构示例日程拍摄。成品采用淡紫灰背景、墨色标题、圆角边框和统一留白。

内置 image_gen 用于初步风格探索（默认内置模式，未使用 API / CLI 图像生成）。提示词保存在 `设计源文件/AI风格探索提示词.txt`。为确保应用文案、按钮和进度数字准确，最终成品直接嵌入真实截图，通过可编辑排版导出，未用 AI 重画界面。只裁去成品中截图的系统状态栏，其余屏幕内容保持原比例。

`原始截图/` 保留实机素材；`设计源文件/` 中的 HTML 可修改标题、字体、颜色、边框和位置，`排版配置.json` 记录文案与素材对应关系。Windows 安装 Chrome 或 Edge 后，可运行其中的 `导出介绍图.ps1` 重新导出（会覆盖本目录的对应成品）。

## 隐私与恢复

所有公开图片均使用虚构日程，不含原用户日程。原始日程、设置、上一份数据备份及首次使用状态在拍摄前完整备份，拍摄后已恢复，并逐文件回读核对 SHA256 一致；恢复后的应用正常显示原有 6 条当日日程、8 条历史及 4/6 完成状态。原数据备份只存放在项目 `.tooling` 私有目录，未放入本图片目录或成品压缩包。

本次未修改应用源码、功能或商店介绍。所有成品经尺寸校验和人工视觉检查。导出文件信息与校验值见 `设计源文件/导出校验.json`。
