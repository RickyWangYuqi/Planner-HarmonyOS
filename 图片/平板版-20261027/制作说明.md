# 序笺 · 本版本平板应用介绍图

制作日期：2026-10-27。对应当前 V1.1.0，包含本轮打卡功能及界面更新。全套由已连接的 HUAWEI MatePad Pro 实拍，设备报告 **API 26 (Release)**，展示当前真实的沉浸光感悬浮底栏和居中编辑面板。

## 成品与顺序

1. **双栏日程**：当日与未来左右并列，分组、进度及独立滚动。
2. **周期打卡**：多个打卡计划、完成与撤销、整体统计。
3. **自动接续**：每期数量、开启状态及下一期名称。
4. **打卡回顾**：日历状态、选中日期内容与补卡入口。
5. **分组与进度**：平板两栏日程编辑面板。
6. **未来安排**：日程内容、分组与起止日期同屏。
7. **个性设置**：日程设置与主题外观分栏展示。
8. **深色主题**：深色双栏主页与悬浮底部导航。

另附 `00-总览.png`，以 4×2 排列八张介绍图。建议按 01–08 顺序使用成品；总览仅用于选图和预览。

## 画面与样例

沿用原 `图片/平板版` 的淡紫灰渐变、墨色标题、圆角平板边框、底部功能标签及深色主题构图。八个画面均为本轮重新拍摄，未将手机界面拉宽，也未重绘应用控件。

拍摄和 UI 定位使用本机通过 npm 安装的 DevEco CLI 1.3.9（项目 `scripts/deveco.ps1`）；通过其 `run --skip-build` 保留数据安装当前构建，启动冒烟检查通过。真实全屏截图为 2800×1840，用固定 HTML 视口展示 `[0,88,2800,1777]` 的应用区域，公开素材为 2800×1689，去除系统状态栏、窗口控制点和底部手势区；成品内再按原比例缩放。

所有日程和打卡内容均为虚构示例。打卡历史通过当前真实业务引擎逐日生成：23/26 期完成，界面按整数显示 89%；当前背单词121–130，每期10个，下一期131–140；10月24日的历史内容为91–100。未来打卡计划只在补卡和时间线中预览，第06张展示的是普通未来日程。

第03张使用编辑页面真实滚动位置，完整展示重复频率、分组和自动接续设置；副标题补充当前与下一期区间。第04张微调滚动位置，使月份、全部日期、选中日期目标及确认补卡按钮同时可见。第06张选中起始日期10月29日，完整展示10月日历。

## 源文件与重新导出

- `原始截图/`：八张本轮应用区域截图，已去除系统栏。
- `设计源文件/*.html`：可编辑标题、文案、背景、平板边框与排版。
- `设计源文件/排版配置.json`：采集信息、截图名、文案、尺寸和布局参数。
- `设计源文件/截图准备校验.json`：原尺寸 HTML 视口准备过程、裁切参数和摘要。
- `设计源文件/导出校验.json`：原图及成品尺寸、字节数与 SHA256。

在安装 Chrome 或 Edge 的 Windows 电脑上，从项目根目录运行：

```powershell
& '.\图片\平板版-20261027\设计源文件\导出介绍图.ps1'
```

导出脚本先检查八张应用区域截图，再用隐藏浏览器与独立 profile 输出八张单图，最后输出总览，自动检查严格3:2尺寸和单张5MB上限。它只覆盖本目录同名成品，不操作平板；修改 HTML 文案时同步更新排版配置，重新导出后同步更新压缩包。

`准备截图.ps1` 仅在重拍后需要运行，依赖本轮私有采集目录中的八张 `-full.png`；普通文案或布局编辑无需重新准备截图。脚本通过原尺寸 HTML 视口输出应用区域，不改变 UI 内容。
