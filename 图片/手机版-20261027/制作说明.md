## 风格与素材

沿用原图片目录的淡紫灰渐变、柔和曲线、墨色双行标题、序笺标识和统一手机边框。新增三张打卡主题，其余主题与原系列衔接。原版图片与平板版均保留。

01–07 使用 HUAWEI Mate 80 Pro Max（API 26）上当前应用的真实截图，取景和截图参考本机通过 npm 安装的 DevEco CLI 1.3.9，使用项目 `scripts/deveco.ps1`。画面中的日程、分组、打卡计划及历史为虚构演示内容；打卡历史按真实业务规则逐日生成，示例中的 121–130 按每期 10 个接续为 131–140，10 月 24 日对应 91–100。

手机画面等比缩放并裁去系统状态栏，没有重绘应用控件。03 为真实滚动位置，使当前名称和下一期名称同时可见。08 复用 2026-10-22 已有的三尺寸透明组件实拍；本轮组件界面未修改，素材按同一 0.7 比例排列，保持尺寸关系。

## 可编辑源文件

- `原始截图/`：七张本轮应用实拍和三张沿用的透明组件图片。
- `设计源文件/*.html`：标题、文案、背景、手机边框及组件排版。
- `设计源文件/排版配置.json`：八张成品与截图的对应关系。
- `设计源文件/组件裁切配置.json`：沿用组件素材的几何参数。
- `设计源文件/导出校验.json`：成品尺寸、字节数及 SHA256。

在安装 Chrome 或 Edge 的 Windows 电脑上，于项目根目录运行：

```powershell
& '.\图片\手机版-20261027\设计源文件\导出介绍图.ps1'
```

脚本先导出八张竖版，再导出引用它们的总览，核对所有成品尺寸并更新校验文件；它会覆盖本目录同名成品，不操作手机。文案改动以对应 HTML 为准，同时维护排版配置。
