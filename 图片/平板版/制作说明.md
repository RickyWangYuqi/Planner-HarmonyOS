# 序笺 · 平板版应用介绍图

与 `图片/` 根目录的手机版介绍图分开存放；本轮未替换或改动任何手机版图片。

## 成图

六张独立 PNG 和一张总览，尺寸统一为 **2880 × 1920px，宽高比严格为 3:2**。全部图片均低于 **5,000,000 字节**（按更严格的十进制 5MB 校验），满足最低 1920 × 1280px 的要求：

1. 双栏日程：当日与未来左右并列、分组与进度。
2. 分组与进度：平板两栏编辑面板。
3. 未来安排：内容与日历同屏安排。
4. 个性设置：日程设置与外观主题分栏。
5. 历史回顾：按日期查看、恢复日程。
6. 深色主题：墨影深色首页。

`序笺-平板版应用介绍图.zip` 包含六张成图、总览与本说明，可单独交付。原始截图和可编辑 HTML 另存在各自子目录。上传应用商店请使用本目录的六张成图；总览用于选图，`原始截图/` 属于未重绘的排版素材，不作为本轮提交图片。

## 截图与隐私

- 2026-10-23 在连接的 HUAWEI MatePad Pro 上运行应用，设备实际截图为 2800 × 1840px；图中为示例日程。
- 没有将手机界面拉宽成平板界面，没有重新绘制按钮、日历或进度等应用 UI。平板边框与宣传文案属于外部排版。
- 公开原图只保留自身应用区域：原始画面 `[0, 88, 2800, 1777]`，裁去状态栏、系统窗口控制点和底部手势区；排版内按原比例缩放，不拉伸。本次尺寸修订从 HTML 源文件重新布局，保留全部文字和界面，没有拉伸或截去旧成图内容。
- 本轮平板此前未安装该应用。截图前备份了新安装后创建的初始数据与首次使用标记；结束后恢复并核对日程、分组、历史和设置。截图期间跨过真实午夜，仅保留系统正常跨日后的当前日期。
- 未读取或修改手机日程；公开图片不含其他应用、桌面壁纸、通知、用户真实日程或设备标识。
- 设备报告 `apiVersion: 24`，画面展示的是当前设备的实际兼容样式，包括普通底栏；不将其描述为 API 26 沉浸材质的真机效果。

## 再次导出

在工程根目录执行：

```powershell
& .\图片\平板版\设计源文件\导出介绍图.ps1
```

需已安装 Chrome 或 Edge。`设计源文件/排版配置.json` 记录画布、文案、截图裁切与校验值；对应 HTML 可修改文案与外部布局；导出脚本会检查最低尺寸、严格 3:2 比例和单张 PNG 的 5MB 上限。导出仅覆盖平板版 PNG，总览最后生成。重新导出后应同步更新压缩包。
