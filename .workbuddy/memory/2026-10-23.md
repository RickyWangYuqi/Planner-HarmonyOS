## 构建 app 包（上架用）与新鲜度校验
- 命令：`devecocli build clean` → `devecocli build --assemble-type assembleApp`。
- 产物：`build/outputs/default/PlanerHarmony-default-signed.app`（含 `entry-default.hap` + `pack.info` + `pac.json`）。
- 校验新鲜度的可靠办法（包里没有编译时间字段，只能看版本与内容）：
  1. `pack.info` 的 `summary.app.version`（code/name）是否为当前版本；
  2. 解包内 `entry-default.hap` 的 `module.json` 版本；
  3. 在 `.abc`/`resources.index` 里搜最近才加的字面量（如 `futureRanges`、`card_seasalt_panel`）确认是本次代码；
  4. 文件 mtime 与本机时间。
- 结论：IDE「构建为 app」输出就在 `build/outputs/default/`，22 号疑虑应是上传页显示的历史上传记录或旧文件；桌面/下载/文档目录下无其它 .app。
- 注意：当前 `signingConfigs` 用的是 DevEco 自动生成的调试证书（alias `debugKey`）。上传 AppGallery 通常需要发布证书与 Profile，否则会被拒。
