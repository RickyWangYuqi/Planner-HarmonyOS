## 卡片第二轮修复（真机反馈 6 项）

- **根因 1（深色背板发灰、正文发虚）**：`backgroundBlurStyle(COMPONENT_THIN)` 的材质色由系统给，不受色板控制，深色下仍是浅灰 → 改为色板半透明背板（深 #EB / 浅 #F2 前缀），彻底移除 blur。
- **根因 2（不随应用深浅色）**：卡片扩展读 `this.context.config.colorMode` 拿到的是**系统**值，而非应用内 setColorMode 覆盖值 → 改为先看 `data.settings.themeMode`，仅 system 时才回落系统值。
- **根因 3（不同步）**：`preferences.getPreferences(context, ...)` 用各自进程的 context，跨进程不共享 → 必须 `context.getApplicationContext()`；另加空注册表时用 `formProvider.getPublishedRunningFormInfos()` 对账。
- **根因 4（圆角错位）**：系统卡片裁剪圆角 + 自绘 border/borderRadius 两套半径叠加 → 去掉自绘圆角、边框与 clip，交给系统。
- **小卡密度**：条目数 1→3（中 4、大 8），行高 19/21/23，新增「另有 N 项」。
- **卡片内勾选完成**：行点击 `postCardAction({action:'message', params:{action:'toggle', id}})` → `onFormEvent` → `CardWriter.toggleToday`（独立 `.card.tmp` + fsync + 校验 + rename + .bak）→ `refreshAll()`；主应用 `foregroundChanged` 用 `PlanerStorage.readRaw` 比对 `adoptedRaw`，采纳外部写入，避免互相覆盖。
- 新增 `services/CardWriter.ets`、`FormBoard.replace`、`PlanerStorage.readRaw`、`Index.adoptExternalChange`；check arkts 30 文件 0 error；test-card 37 项 + 其余全通过；已安装真机。

## 卡片第五轮（颜色同步时机 / 定位贴底判定）
- 从卡片 router 进入应用时，被点的那张卡会等回到桌面才重绘，颜色看起来“退出后才变”。两处加固：
  ① `EntryAbility.onBackground()` → `AppStorage['planerBackground']` → Index `@Watch` 里再 `syncForm()` 一次，
     离开应用前把最新配色推给所有实例；
  ② `FormSync.reconciled` 原来只在注册表为空时才与 `getPublishedRunningFormInfos()` 对账，若注册表漏了某个实例，
     那张卡只能等系统重新绑定。改为每次推送都对齐运行中的卡片（补齐缺失、剔除已移除）。

  改为 `last.y + last.height <= viewport + 1`，只在真正到底时跳过。
